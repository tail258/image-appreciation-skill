## 1. 分析原则

把鉴赏视为“证据—机制—结论”模型：

`可见证据 → 视觉系统如何组织注意与空间 → 观看者更可能形成的情绪和叙事体验`

先描述关系而非对象清单。与“画面中有树、云和人”相比，“人物只占画面很小比例，深色树群包围亮部天空”更能支持尺度、脆弱性和空间压力的推断。

同一参数没有固定含义。低饱和度可能产生宁静，也可能产生衰败；必须结合明度、对比、边缘、构图和题材共同判断。

## 2. 共同基础维度

### 色彩

- **色相结构**：主色、辅助色、强调色；互补、邻近、单色或分裂互补关系。
- **冷暖组织**：整体温度、局部冷暖反转、前暖后冷或反向纵深。
- **饱和度**：统一压低、局部高饱和焦点、纯度梯度；判断它如何控制刺激强度。
- **明度与对比**：高调、低调、明暗跨度、主体与背景的分离度。
- **色量与分布**：颜色不是只看种类，还要看面积、位置、重复节奏和视觉重量。

典型链路：`大面积低饱和冷色 + 小面积暖色 → 视觉先感到广阔冷静，再被暖色锚点吸引 → 形成疏离环境中的微弱亲近感`。

### 光影

- 判断光源方向、数量、软硬、色温、覆盖范围与是否符合物理逻辑。
- 分析顺光、侧光、逆光、顶光、底光如何塑造体积、面部可读性和戏剧性。
- 观察暗部是否保留细节，亮部是否溢出，轮廓光是否让主体从背景脱离。
- 区分“照明功能”和“叙事功能”：光是否像舞台一样选择性揭示信息。

典型链路：`柔和侧逆光 + 暗部保留细节 → 边缘被轻柔分离且没有强烈威胁阴影 → 形成亲近但略带距离的观看关系`。

### 构图与视线

- 标记视觉焦点、次焦点、进入点、视线移动方向和停止位置。
- 判断中心、偏心、三分、对角、三角、框景、对称、重复、放射等组织方式。
- 分析主体大小、位置、朝向、裁切与画外空间；确认画面是稳定、悬置还是倾斜推进。
- 观察前景遮挡、引导线、明暗边界、色彩跳点和面部/文字等注意力磁体。

典型链路：`主体偏离中心并朝向画外 → 视线被引向未显示区域 → 叙事信息保持未闭合 → 产生等待、悬念或离场感`。

### 空间与尺度

- 分析前中后景、透视、重叠、空气透视、景深、雾化、尺度参照与负空间。
- 判断观看距离：特写制造侵入或亲密，远景制造环境支配或沉思距离。
- 判断空间可进入性：路径是否清晰、边界是否封闭、观看者处于内部还是外部。
- 注意平面化并不等于缺少空间，它可能把注意力从现实纵深转向图案、节奏与符号。

### 线条、形状与节奏

- 比较直线/曲线、锐角/圆形、连续/断裂、均匀/抖动、粗/细、硬边/软边。
- 分析轮廓是否封闭，形状是向外扩张、向内收缩、上升、下坠还是旋转。
- 观察重复、间隔、密度和方向变化怎样控制速度感与呼吸感。

### 材质、细节与媒介

- 观察光滑/粗糙、透明/不透明、干湿、厚薄、颗粒、笔触、线稿、噪点、渲染精度。
- 比较细节密度的区域差异；高细节通常吸引停留，低细节负责留白、速度或氛围。
- 区分媒介事实与视觉效果。无法确认油画、数码绘画、摄影或生成图像时，只描述可见的媒介感。
- 分析“完成度”是否均匀；局部未完成可能是注意力设计，不必自动视为缺陷。

## 3. 人物与动漫角色

### 姿态与身体结构

- **开放/防御**：胸腔、手臂和腿部是展开还是保护核心区域；身体是否被衣物、道具或画框遮挡。
- **张力/松弛**：肩颈高度、脊柱曲度、重心、关节角度、手指状态是否显示用力。
- **稳定/失衡**：支撑面、倾斜角度、悬空感与动态线是否制造控制或失控。
- **关系性**：身体朝向观看者、他者、物件还是画外；距离与接触方式如何定义亲密程度。

### 视线与表情

- 区分直视、回避、上抬、下移、侧望、闭眼以及视线目标是否可见。
- 观察眉眼开合、瞳孔可见度、嘴角、唇部张力、下颌、面部不对称，而非只给表情命名。
- 直视不必然自信；结合头部角度、身体收缩和光线遮蔽判断它是邀请、对抗还是脆弱暴露。

### 造型与风格化

- 分析发型、服装轮廓、配饰、色彩编码、比例夸张和线条软硬如何塑造角色可读性。
- 动漫或高度风格化角色的眼睛、脸型和姿态经过符号化处理，应解释其图形功能，不按真人生理解剖机械判断。
- 把心理结论写成“画面将角色建构为……”，避免把图像表现当成现实人格证据。

人物链路示例：`肩部内收 + 手臂靠近躯干 + 视线仍直视观看者 → 身体防御与眼神接触同时存在 → 形成想靠近但仍在自我保护的矛盾亲密感`。

## 4. 风景与环境

- **地平线与视点**：低地平线放大天空，高地平线强调地表；俯视偏向掌控，仰视强化崇高或压迫。
- **尺度参照**：人物、树木、建筑、道路和飞鸟让自然尺度可感；缺少参照会提高抽象性和不确定性。
- **纵深与路径**：河流、道路、山谷、光带是否邀请视线进入，还是以峭壁、密林、雾幕阻断进入。
- **天气与时间**：雾、雨、风、云层、晨昏与季节通过能见度、边缘和色温改变时间感。
- **静止与运动**：水面、云、植被、沙尘和笔触方向决定场景是凝固、呼吸还是剧烈变化。
- **自然与人工**：人工痕迹的密度、尺度和维护状态会改变庇护、孤独、秩序或遗弃感。

风景链路示例：`低地平线 + 大面积云层 + 极小人物参照 → 天空获得压倒性尺度，人物控制感降低 → 生成崇高感，并混入轻微的脆弱或敬畏`。

## 5. 抽象与非具象

- 以色块、边缘、密度、方向、重复、层叠、空白、表面痕迹和重力感为主要证据。
- 判断视觉事件是扩散、碰撞、堆积、切割、漂浮还是坠落。
- 分析秩序与扰动比例：规则重复提供预测性，局部破坏提供注意力和张力。
- 不急于给形状附会具体故事；先解释形式如何作用于身体感、速度感和空间感。

抽象链路示例：`均匀网格被一处高饱和斜线切断 → 预测节奏突然中止 → 注意力被异常点捕获 → 形成控制系统中短暂失控的兴奋感`。

## 6. 建筑、室内、静物与产品

- **建筑/室内**：分析几何秩序、轴线、尺度、采光、动线、边界、材质转换与人体可达性。
- **静物**：分析物件选择、排列、遮挡、表面状态、使用痕迹和象征关系；避免无证据的固定象征解释。
- **产品/商业图**：分析轮廓辨识度、材质可信度、功能暗示、品牌色、负空间和视觉层级。
- 判断物体是被“展示、使用、保存、遗弃还是纪念”；用摆放和光线证据支持叙事判断。

## 7. 视觉—情绪模型

模型标签必须从结构中归纳，可以组合，也可以为特定作品另拟名称：

- **脆弱依赖型**：低防御姿态、接近性线索和不稳定支撑并存。
- **克制压抑型**：低饱和、压缩空间、受限动作和低情绪外显共同抑制释放。
- **温柔疏离型**：柔和媒介与光色降低威胁，但距离、回避或留白阻止完全接近。
- **高控制冷感型**：几何秩序、硬边、对称或精确表面提高掌控感，同时降低触觉亲近。
- **低防御亲密型**：近距离、开放姿态、柔光和高面部可读性共同减少观看阻力。
- **开阔崇高型**：巨大尺度、强纵深和自然力削弱个体控制，产生敬畏与扩张感。
- **静谧庇护型**：柔和边界、可进入路径、稳定水平线和低刺激色彩形成安全容器。
- **荒寂停滞型**：稀疏参照、弱运动、磨损材质和封闭色域延长时间感。
- **暧昧未决型**：遮挡、画外空间、矛盾线索和信息缺口保持叙事悬置。

输出格式：`主要模型（必要时 + 次要模型）：证据组合 → 感知关系 → 模型成立原因`。

## 8. 吸引力机制

至少识别一个主要机制，并说明它如何工作：

- **情绪可读性**：表情、姿态、色光关系让状态易于识别，降低理解成本。
- **低防御或可进入性**：人物显得可接近，或空间提供清晰入口，使观看者容易代入。
- **未完成感**：画外视线、遮挡、停顿动作、模糊背景或缺失前因后果促使观看者补全。
- **控制与失控**：秩序提供安全预测，局部扰动制造活力；两者比例决定紧张程度。
- **熟悉与陌生**：可识别题材提供入口，异常比例、色彩或组合延长凝视。
- **尺度反差**：巨大与微小、空旷与密集、细腻与粗粝的并置强化感知。
- **节奏与回报**：重复引导扫描，焦点、细节和彩色跳点为视线提供阶段性回报。
- **感官模拟**：光泽、颗粒、雾、水、织物或皮肤质感唤起触觉、温度和空气感。
- **叙事缺口**：可见结果与不可见原因之间的差距激发推理。
- **技法展示**：笔触、线条、渲染、光影或材料控制本身构成观看快感。

避免把“吸引力”写成“元素很多”或“画得精细”。说明注意力为什么被捕获、怎样被维持，以及为何愿意再次观看。

## 9. 证据强度与常见误区

- **高置信**：可直接观察的颜色、位置、边缘、姿态和明暗关系。
- **中置信**：由多条视觉证据共同支持的情绪、叙事和空间判断。
- **低置信**：作者意图、身份、历史背景、固定象征和具体故事；无外部资料时明确限定。
- 不按元素逐项套词典；同一元素必须放回整体关系。
- 不把角色表情等同于现实人物心理诊断。
- 不因精细度高就自动判断“更高级”，也不因简化就判断“未完成”。
- 不只解释焦点，也解释次要区域如何衬托、延迟或抵消焦点。
- 不遗漏反证。若画面同时支持两种情绪，说明矛盾如何成为作品的核心张力。
